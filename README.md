# Entrega Tech Challenge - Data Analytics (FIAP)

Projeto desenvolvido na Pós-Tech em Data Analytics da FIAP, utilizando o dataset público de e-commerce da Olist.

## Objetivo da análise

Analisar o desempenho logístico dos pedidos, os prazos de entrega, os atrasos e sua relação com a satisfação dos clientes, identificando oportunidades de melhoria e gerando recomendações para o negócio.
